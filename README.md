# Knowledge Garden

This repository serves as my personal knowledge base for collecting, organizing, and revisiting information and ideas across different subjects.

## Purpose

The primary purpose of Knowledge Garden is to preserve and organize information I have learned, explored, or found useful, making it easier to revisit and reference in the future.

The process of organizing and documenting knowledge also provides opportunities to deepen my understanding through explanation, implementation, experimentation, and verification.

The content may include:

- Fundamental concepts and more advanced topics.
- Notes and explanations for quick review.
- Questions, ideas, and personal observations.
- Code examples, practical experiments, and their results.
- Interactive demonstrations and visualizations when useful.

The goal is not to create a comprehensive tutorial for every subject, but to build a personal reference that can be corrected, expanded, and reorganized over time.

## Approach to AI

I view AI as a tool that can assist with learning, writing, programming, and development, much like other tools used in software engineering.

Using AI effectively requires more than generating an answer. It also requires understanding the output, evaluating its correctness, and knowing how to verify it.

AI-generated content should not be accepted simply because it appears convincing.

I believe that the person who chooses to use and submit AI-generated work should take responsibility for the final result, including its correctness, quality, and limitations.

AI can assist in producing work, but understanding, verification, and accountability remain the responsibility of the person using it.

## Engineering Practice

Knowledge Garden also serves as a practical environment for learning and applying software engineering practices, including:

- Git and GitHub development workflows.
- Code review, testing, and project maintenance.
- Continuous Integration and Continuous Deployment (CI/CD).
- Automation and AI-assisted development.

These practices will be explored and refined as the project evolves.
